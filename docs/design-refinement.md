# 青い制作展示室

## Direction
- Product: 制作物と担当内容を伝えるポートフォリオ
- Character: 探究的、端正、少し遊び心
- World: 青い空間に作品を展示する制作室
- Moments: 公開済みアプリの実画面
- Signature: 作品名に添える制作番号

## Audit and changes
- Spacing: セクション間80/112px、プレビュー内16/24px、制作一覧32pxへ整理
- Color: 白系の主文、青白い補助文、黄緑の操作強調へ役割分け。ユーザー指定の青を維持
- Icons: 装飾追加を避け、既存の外部リンク矢印のみ使用
- Copy: 制作分野が伝わる見出し、日本語のセクション名、作品説明を表示
- Type: Noto Sans JPとIBM Plex Mono、400/500を中心に統一
- Layout: 全画面ヒーローと作品グリッドを維持。実画面と説明を主役に
- Details: 罫線と選択状態を静かにし、スクリーンショットを明示
- Visuals: まるごと祭アプリ、PaperBrowser、Tokariumの既存実画像を使用。画像生成なし
- Motion: 常時動く粒子と光を削除。作品切替は初期停止し、任意で再生可能。ユーザー指定の初回エージェント演出は維持

## ASCII workshop / subsequent user direction
ユーザー指定で雰囲気を大きく変更。青黒い端末色、ASCIIのYUTAロゴ、文字の地形、ロボットと端末の挿絵、破線の罫線を採用。作品プレビューは元画像をブラウザ内でASCII文字列へ変換し、実画面へ切り替え可能。画像の加工ファイルは生成せず、元の作品画像を保持。装飾アートは読み上げ対象外。
